
# University Performance & Analytics Dashboard

## Project Overview
An interactive Power BI dashboard developed to analyse university-level performance and institutional KPIs across academic programmes.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX

## Key Performance Indicators
- Total Students
- New Admissions
- Academic Performance %
- Placement %
- Faculty Count
- Revenue (₹ Crore)
- Student-Faculty Ratio

## Analysis Areas
- Programme-wise student analysis
- Admission trends
- Academic performance monitoring
- Placement performance
- Faculty strength
- Revenue analysis
- Student-faculty ratio

## Project Objective
To bring key university performance indicators together in an interactive dashboard and support institutional monitoring and data-driven decision-making.

## Project File
`University Dashboard.pbix`

Open the file using Microsoft Power BI Desktop.
